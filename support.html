云序对话 / Yunxu Chat · V0.1.12

使用问题、兼容性问题或隐私问题可发送邮件至 9072686@qq.com。

反馈前建议

  • 说明使用的浏览器（Chrome / Edge）及版本。
  • 说明发生问题的 AI 网站和操作类型（Markdown / JSON / PDF / 复制 / 批量）。
  • 可在“关于 → 导出诊断信息”生成本地诊断 JSON。诊断日志不包含聊天正文；发送前仍请自行检查文件内容。
  • 不要发送密码、Cookie、访问令牌或其他认证材料。

隐私

扩展不会自动上传诊断文件或聊天正文。只有你主动通过邮件等渠道发送材料时，开发者才会看到你选择提供的内容。
